# Experiments

Use [`manifest.template.toml`](manifest.template.toml) as the starting point for each reproducible run. Replace placeholder values with actual configuration and measured observations. Keep `status = "not_run"` until execution begins; never present template values as results.

Record the experiment identifier, model or fixture identity and hash where available, transformation and seed, hardware/software versions, Git commit, evaluation method, resource budgets and observations, results, limitations, outcome, and safe report artifacts. Mark unmeasured metrics explicitly. Do not place model weights, private datasets, secrets, or personal data in this directory or in Git history.
