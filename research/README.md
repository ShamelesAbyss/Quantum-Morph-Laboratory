# Research index

This directory contains sourced literature reviews, reproducible notes, and experiment records. The first prior-art batch has been completed for 17 topics; see [`prior-art-index.md`](prior-art-index.md) for the navigational index and [`prior-art-synthesis.md`](prior-art-synthesis.md) for a comparative analysis. Detailed notes are in [`literature/`](literature/).

This is a partial review, not comprehensive prior-art or patent research. Behavioral methods, interpretability, distillation, evolutionary optimization, quantum-inspired optimization, complex-valued neural networks, and additional compression and file-format methods remain to be reviewed. No QML method or result in the first batch was independently reproduced by this project.

## Evidence labels

- **Established result/method:** supported by primary research or authoritative documentation; the source and conditions must be cited.
- **Independently reproduced:** QML has run a documented replication with code, environment, data provenance, and results.
- **Untested hypothesis:** a proposed question or mechanism without validating experiment.
- **QML experimental contribution:** a result generated by this project; claims require comparison to prior art and reproducibility artifacts.

Every reviewed method should record its title, authors, publication date, DOI/arXiv/canonical URL, mathematical principles, reported results, compute requirements, limitations, licensing, QML relevance, and potential overlap. A source link alone is not a novelty analysis. State explicitly when a detail is unreported or unverified rather than inferring it.

Start with the [novelty ledger](novelty-ledger.md). RMQ and MAP remain working names, not evidence of originality. The current review identifies relevant prior art but does not establish novelty, priority, freedom to operate, or non-infringement.
