# Contributing

The project is an early research scaffold. Contributions should be small, testable, and explicit about evidence and limitations.

- Discuss scientific proposals with primary-source citations and a baseline plan.
- Keep proposed methods distinct from established results and independently reproduced results.
- Add deterministic tests for mathematical behavior and edge cases.
- Report measured results with hardware/software configuration; label estimates as estimates.
- Never commit model weights, private datasets, credentials, or generated artifacts that are not licensed for redistribution.
- Use Rust and avoid Python development or runtime dependencies.
- Run the checks in [BUILD.md](BUILD.md) before submitting changes.
- The repository license is pending owner selection; do not assume inbound or outbound reuse terms until it is added.
