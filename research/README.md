# Research index

This directory is the home for sourced literature reviews, reproducible notes, and experiment records. The broad prior-art review required by the project directive has **not yet been completed**. No citations or experimental results are asserted by this scaffold.

## Evidence labels

- **Established result:** supported by primary research and corroborating evidence; sources and conditions must be cited.
- **Independently reproduced:** QML has run a documented replication with code, environment, data provenance, and results.
- **Untested hypothesis:** a proposed question or mechanism without validating experiment.
- **QML experimental contribution:** a result generated by this project; claims require comparison to prior art and reproducibility artifacts.

Every reviewed method should record its title, authors, publication date, DOI/arXiv/canonical URL, mathematical principles, reported results, compute requirements, limitations, licensing, QML relevance, and potential overlap. A source link alone is not a novelty analysis.

Start with the novelty ledger in [`novelty-ledger.md`](novelty-ledger.md). Do not interpret working names such as RMQ or MAP as evidence that a method is original.
